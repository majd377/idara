# V26 — الرسائل بدون كسور عشرية

تم تعديل تنسيق المبالغ المالية الظاهرة للمستخدم لتظهر كأعداد صحيحة فقط، بدون .00 أو أي كسور عشرية.

- سحب المياه يبقى بدقة 3 منازل عشرية (مثال: 2.511 كوب) لأنه كمية استهلاك.
- جميع مبالغ الرسالة: المياه، الحارس، المصاريف، الديون، الإجمالي قبل الدفعات، الدفعات، الإجمالي المطلوب = أعداد صحيحة.
- المبالغ المالية الأخرى في الواجهة تستخدم نفس سياسة التقريب لأقرب شيكل.
