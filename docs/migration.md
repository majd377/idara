# الترحيل من Excel — Data Dictionary وحالات المراجعة

## المصدر
`برنامج_حسابات_عمارة_الأمين_الاحترافي.xlsx` — شيت **"المشتركون"** (الصفوف 5-41)، مُستخرج حرفيًا
ومُنفَّذ في `src/db/import-legacy-subscribers.ts`. تشغيله: `npm run db:import-legacy` (آمن لإعادة التشغيل — idempotent).

## Data Dictionary (Excel → DB)
| عمود Excel | المعنى | يذهب إلى |
|---|---|---|
| الكود | معرّف Business ثابت (`1-01`...) | `subscribers.code` و`units.code` |
| اسم المشترك | اسم الشخص/المحل | `subscribers.name` |
| البناية | رقم العمارة (1/2/0) | `buildings.code` (0 = مشترك خارجي، بلا بناية) |
| الدور | الطابق/الوصف (الارضي/حاصل/سده/رقم) | `units.floorLabel` |
| النوع | داخلي/خارجي | `subscribers.subscriberType` |
| رقم الهاتف | هاتف المشترك | `subscribers.phone` (فارغ لمعظم السجلات فعليًا) |
| رسم الحارس الافتراضي | 0 أو 30 ₪ | `subscribers.defaultGuardFee` |
| تأمين الغاطس الافتراضي | 0 أو 15 ₪ | `subscribers.defaultPumpInsuranceFee` |

## نتيجة التنفيذ الفعلي (تحقّقنا منها، وليست افتراضًا)
```
✓ عمارة 1: 23 وحدة (1-01 → 1-23)
✓ عمارة 2: 13 وحدة (2-01 → 2-13)

```
