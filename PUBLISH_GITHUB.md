# نشر سريع
1. احذف الملفات القديمة من مستودع GitHub.
2. ارفع الملفات من هذا المجلد مباشرة إلى الجذر.
3. Settings → Pages → Deploy from branch → main → /(root).
4. افتح الموقع ثم Ctrl+Shift+R.
5. Firebase Authentication → Google enabled.
6. Firebase Authentication → Settings → Authorized domains → `majd377.github.io`.
7. Firestore Database → Rules → الصق `firestore.rules` ثم Publish.
