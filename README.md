# عمارة الأمين — V36

نسخة معاد ترتيبها اعتمادًا على النسخة المستقرة السابقة، مع إضافة/إبقاء قسم الإيرادات وصندوق العمارة داخل نفس الموقع، وإضافة إجمالي مديونية السكان في صفحة السكان.

## التشغيل
- ارفع محتويات المجلد إلى جذر GitHub Pages.
- Firebase config موجود في `firebase-config.js`.
- قواعد Firestore في `firestore.rules`.
- البيانات المضمنة الحالية في `initial-data.js`.
