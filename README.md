# عمارة الأمين — V6 Easy & Fancy

نسخة عربية RTL تركز على سهولة الاستخدام اليومية.

## أهم التحديثات
- تنقل سريع: لا يعيد تحميل كل بيانات Firebase عند الانتقال بين الأقسام؛ التحديث الكامل يتم فقط بزر «تحديث» أو بعد عمليات تتطلب مزامنة.
- خط أكبر قليلًا ووضوح أعلى.
- فصل واضح بين الإدارة اليومية والتقارير والمساعدة والإعدادات.
- دليل استخدام عملي متعدد الخطوات مع أمثلة فعلية وأزرار انتقال مباشرة.
- السكان: تعديل البيانات مع الحفاظ على التاريخ.
- قراءات الماء: السابقة والحالية قابلة للتعديل.
- تقارير وتصدير Excel.
- Firebase Authentication + Firestore.

## تشغيل محلي
Node.js 22+ ثم:

```bash
npm install
npm start
```

## GitHub Pages
ارفع الملفات الثابتة إلى الجذر. التطبيق يستخدم Firestore مباشرة من المتصفح ولا يعتمد على `/api/...` على GitHub Pages.

## ملاحظات
- لا ترفع أي Service Account JSON أو Private Key أو ملفات `.env`.
- `firestore.rules` جزء من المشروع ويمكن رفعه إلى GitHub.
