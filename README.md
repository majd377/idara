# عمارة الأمين — نظام إدارة الحسابات

## V33 — صندوق العمارة مدمج داخل نفس التطبيق

هذه النسخة مبنية على النسخة التي كانت تعمل، مع إضافة قسم **صندوق العمارة والإيرادات** داخل نفس الموقع، وليس كتطبيق أو صفحة مستقلة.

### الأقسام الجديدة داخل الموقع
- نظرة عامة للصندوق
- خدمة الحارس الشهرية
- استلام وبيع السولار
- صندوق العمارة ومصروفاته
- إيرادات أخرى

بيانات الصندوق تستخدم Collections مستقلة في Firestore ولا تدخل في حسبة المياه أو سعر الكوب.

### ملاحظات
- `Abo Zaid` و`Al-Suwaisi` وحسبة المياه تبقى كما هي في النظام الأساسي.
- المولد الخارجي لا يتحول إلى مصدر كهرباء أساسي من خلال هذا القسم؛ يمكن تسجيله في المصاريف النظامية.
- خدمة الحارس شهرية مستقلة.
- صافي السولار يذهب إلى صندوق العمارة.
- الإصدار الحالي لا يحتاج `fund.html`؛ الصندوق يظهر داخل `index.html` الرئيسي.
