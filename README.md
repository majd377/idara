# عمارة الأمين — V23 FINAL

هذه النسخة تستخدم أسماء ملفات جديدة عمدًا لتجاوز Cache في GitHub Pages.

ارفع كل الملفات في جذر المستودع، ثم Settings → Pages → main → /(root).
بعد النشر افتح الموقع مع Ctrl+Shift+R.

المشروع لا يحتوي Excel Import ولا ملفات Excel حقيقية. لا ترفع أسرار Firebase أو Service Account.
