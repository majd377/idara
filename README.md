# عمارة الأمين — الإصدار V9

نسخة GitHub Pages + Firebase/Firestore لإدارة حسابات العمارة.

## ما الجديد في V9

- قسم مستقل أعلى صفحة **قراءات الماء** لقراءات المياه الإجمالية:
  - البناية الأولى
  - البناية الثانية
  - الخارجي
- لكل جهة: قراءة سابقة + قراءة حالية + استهلاك محسوب تلقائيًا.
- إجمالي استهلاك المياه للأسبوع = مجموع الجهات الثلاث.
- سعر الكوب يُحسب اعتمادًا على إجمالي المياه الإجمالي، ثم يُرفع للعدد الصحيح الأعلى.
- مقارنة استهلاك العداد الإجمالي مع مجموع استهلاك سكان البناية للمراجعة فقط.
- اختيار الأسبوع من **قائمة منسدلة** بدل بطاقات كثيرة.
- الأسبوع يملك تاريخ بداية ونهاية يختارهما المدير من التقويم، بدون افتراض أن يوم القراءة ثابت.
- عند فتح أسبوع جديد، تنتقل القراءات السابقة تلقائيًا لعدادات الماء والكهرباء وقراءات الإجماليات.
- الحفاظ على Firebase/Firestore وORG_ID الحالي.

## النشر على GitHub Pages

ارفع محتويات هذا المجلد مباشرة إلى جذر المستودع، ثم:

Settings → Pages → Deploy from a branch → main → /(root)

لا ترفع مفاتيح Service Account أو أي أسرار خادم.


## V10 — تحديثات الحساب والتقارير
- استهلاك البناية الأولى والثانية يحسب تلقائيًا من مجموع قراءات سكان كل بناية.
- الاستهلاك الخارجي يدخل يدويًا في قسم إجمالي المياه.
- إجمالي المياه المستخدم في سعر الكوب = البناية الأولى + البناية الثانية + الخارجي.
- الحفظ التلقائي مفعل أثناء إدخال قراءات السكان والطاقة والخارجي، مع زر "حفظ الآن".
- التقارير تحتوي على كشف حساب بصري للساكن مع الرصيد السابق والمياه والخدمات والدفعات والرسالة الجاهزة للنسخ.
- يمكن طباعة كشف الساكن مباشرة من الموقع.
