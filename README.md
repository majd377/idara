# عمارة الأمين — V23

نسخة عربية RTL مرتبطة بـ Firebase/Google/Firestore.

## أهم ما فيها
- V23 مبنية على أساس V17 المستقر.
- خدمة الحارس مستقلة مع مبلغ للشخص واستثناء سكان.
- المساهمات والخصومات مستقلة وتخفض تكلفة تشغيل المياه قبل سعر الكوب.
- الدفعات مرتبطة بالأسبوع ولا تتكرر في الأسابيع التالية. المتبقي/الزيادة فقط يترحل.
- الدين السابق يُسجل كرقم مستقل.
- حساب أسبوعي قابل للمراجعة.
- كشف ساكن حسب الأسبوع ورسالة جاهزة.
- تنزيل كشف حساب PDF للجدول فقط.
- حذف للبيانات التشغيلية بصلاحيات.
- حفظ تلقائي للقراءات مع حفظ فوري عند الضغط على حفظ الكل.
- البيانات المضمنة في الكود هي أسبوع 03/09/2026 فقط.
