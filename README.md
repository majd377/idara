# عمارة الأمين — v5 Easy & Fancy

واجهة عربية RTL بسيطة لإدارة سكان العمارة وقراءات المياه والمصاريف والدفعات والتقارير.

## أهم ما في هذه النسخة
- Google Login عبر Firebase Authentication.
- بيانات مشتركة بين الحسابات عبر Firestore.
- Local Cache في Firestore لدعم العمل الأسرع والانقطاع المؤقت.
- المدير الرئيسي: `mjdshbyr449@gmail.com`.
- إضافة وتعديل وأرشفة السكان.
- تعديل القراءة السابقة والحالية في نفس الجدول.
- فتح/حذف أسبوع بصلاحيات مناسبة.
- تسجيل الدفعات.
- تسجيل المصاريف.
- تقارير Excel حقيقية عند توفر SheetJS، مع CSV fallback إذا تعذر تحميل المكتبة.
- تصميم أخف وأوضح من النسخ السابقة.

## GitHub Pages
راجع `PUBLISH_GITHUB.md`.

## أمان
قواعد Firestore موجودة في `firestore.rules`. لا ترفع Service Account JSON أو أي Private Key.
