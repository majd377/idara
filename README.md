# نظام إدارة حسابات عمارة الأمين

نسخة أولية فعلية قابلة للتشغيل محليًا، مبنية حول قاعدة SQLite وواجهة عربية RTL وAPI بسيط بدون الحاجة لحزم خارجية في نسخة Python.

## تشغيل سريع

```bash
python3 app.py
```

ثم افتح: `http://localhost:3000`

على Windows يمكن تشغيل `run.bat`، وعلى Linux/macOS يمكن تشغيل `./run.sh`.

## ماذا تم تنفيذه؟

- قاعدة بيانات منظمة للحسابات.
- عمارات ووحدات ومشتركين وعدادات مياه.
- فترة حسابية أسبوعية.
- إدخال قراءات المياه مع الحالات والتحقق من القراءة السالبة.
- مصادر الطاقة وقراءات المولدات.
- التكاليف التشغيلية.
- محرك حساب مركزي لاستهلاك المياه وسعر الوحدة.
- قاعدة ROUNDUP لسعر الوحدة.
- Water Charges وLedger.
- تسجيل الدفعات وتحديث دفتر الحساب.
- كشف حساب المشترك.
- سجل تدقيق Audit Log.
- لوحة تحكم عربية.
- بداية بيانات مأخوذة من ملف Excel المرفق.

## تطوير لاحق مطلوب قبل الإنتاج

- ترحيل كامل لكل الصفوف التاريخية مع reconciliation أسبوعي مقابل Excel.
- محرك توزيع مصاريف كامل لكل القواعد (حسب الاستهلاك/بالتساوي/بناية/مجموعة/مشترك).
- خدمات دورية مع حماية من التكرار.
- صلاحيات وتسجيل دخول فعلي.
- إقفال واعتماد الفترات.
- تقارير PDF/Excel.
- تكامل WhatsApp رسمي.
- مرفقات وتخزين ملفات.
- PostgreSQL للإنتاج والنسخ الاحتياطي الاحترافي.
