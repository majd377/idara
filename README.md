# عمارة الأمين — نظام إدارة الحسابات

نسخة سهلة وموجهة للعمل الحقيقي على GitHub Pages + Firebase.

## أهم دورة عمل

1. **السكان والوحدات**: حدد البنايات والوحدات وأضف السكان، الداخلي أو الخارجي.
2. **الأسابيع والحساب**: افتح أسبوعًا جديدًا. القراءة السابقة للماء والكهرباء تنتقل تلقائيًا من آخر قراءة مسجلة.
3. **الكهرباء والمولدات**: لكل مولد أدخل السابقة والحالية وسعر الكيلو. البرنامج يحسب الاستهلاك والتكلفة.
4. **قراءات الماء**: لكل ساكن أدخل السابقة والحالية. الاستهلاك = (الحالية − السابقة) ÷ 1000.
5. **المصاريف والطوارئ**: أضف السولار، استئجار مولد خارجي، النقل، الصيانة، والطوارئ. المساهمة/الخصم يقلل التكلفة.
6. **الخدمات الدورية**: من حساب الأسبوع أضف خدمة الحارس وتأمين الغاطس، مع منع التكرار لنفس الفترة.
7. **احسب الأسبوع**: التكلفة الصافية ÷ مجموع استهلاك البناية الأولى + الثانية + الخارجي = السعر الخام، ثم رفعه للعدد الصحيح الأعلى، ثم استهلاك كل ساكن × سعر الكوب.
8. **الدفعات والأرصدة**: كل دفعة تسجل في دفتر الحركات وتنعكس على الرصيد.
9. **التقارير والتصدير**: تنزيل السكان، قراءات الماء، الكهرباء، الدفعات، الأرصدة وملخص الحساب بصيغة Excel.

## Firebase

- Authentication: Google
- Firestore: قاعدة البيانات المشتركة
- Local cache: دعم تصفح/عمل مؤقت بدون اتصال حسب دعم Firestore للمتصفح
- Security Rules: ملف `firestore.rules`

## GitHub Pages

ارفع محتويات هذا المجلد إلى جذر المستودع، ثم:

`Settings → Pages → Deploy from branch → main → /(root)`

Authorized domain في Firebase:

`majd377.github.io`

## مهم

لا ترفع ملفات Service Account أو أي Private Key إلى GitHub. إعدادات Firebase Web الموجودة في `firebase-config.js` هي إعدادات عميل الويب وليست Service Account credentials.
